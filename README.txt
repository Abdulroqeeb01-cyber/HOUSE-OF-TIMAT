HOUSE-OF-TIMAT — LUXURY READY-TO-WEAR STORE

CUSTOMER PAGES
- index.html — Home
- shop.html — Collection and category filters
- about.html — Brand story
- faq.html — FAQs
- contact.html — Contact/enquiry page
- wishlist.html — Saved products

ADMIN
- admin.html — Sales, orders, catalogue and stock dashboard

FEATURES
- HOUSE-OF-TIMAT branding with an ivory, espresso and champagne-gold visual identity
- Separate pages, responsive navigation, home icon, cart icon and wishlist
- Product catalogue, category filters, add to cart, saved products
- Demo checkout can record a preferred payment option: Paystack, Flutterwave or bank transfer
- Admin can add/edit/delete products and monitor stock and demo orders

RUN
Extract the ZIP and open index.html. Open admin.html for the admin dashboard.

IMPORTANT
This is a front-end demo. Payment options are displayed and the selected option is stored with a demo order, but NO actual payment is collected. For live payments, integrate Paystack and Flutterwave securely on a backend, implement bank-transfer confirmation, verify transactions server-side with webhooks, and never trust browser-only order records. Add secure admin authentication and a production database before launch. Update placeholder contact details and product content with the brand's real information.
